# Учёт личных расходов студента

Веб-приложение для ведения личных расходов студента. Оно помогает быстро записывать траты, просматривать расходы за выбранный месяц и видеть общую сумму и разбивку по категориям.

## Что реализовано

- Добавление расхода: сумма, категория, дата и необязательное описание.
- Проверка данных на клиенте и на сервере: сумма должна быть положительной, дата — в формате `YYYY-MM-DD`, категория не может быть пустой.
- Просмотр расходов за выбранный месяц.
- Подсчёт общей суммы и расходов по категориям.
- Удаление отдельной записи и очистка всех данных.
- Пагинация списка расходов по 25 записей.
- Тестовая панель: генерация 2000 записей для проверки интерфейса на большом объёме данных.
- API для проверки состояния сервера и работы с расходами.

## Как работает решение

Пользователь открывает страницу приложения, выбирает месяц и добавляет расход через форму. Фронтенд отправляет запрос на API, сервер валидирует и сохраняет запись в `data.json`. Затем интерфейс запрашивает расходы выбранного месяца, рассчитывает итоговые суммы и отображает список с разбивкой по категориям.

## Технологии

- Python
- FastAPI
- Pydantic
- Uvicorn
- HTML, CSS и JavaScript
- React 18 и ReactDOM 18, подключаемые через CDN
- Babel Standalone для обработки JSX в браузере
- JSON-файл как локальное хранилище

AI-модели, внешние API и сторонние сервисы в проекте не используются.

## Архитектура

```text
Браузер (React-интерфейс из static/index.html)
                 |
                 | HTTP-запросы /expenses
                 v
FastAPI-приложение (main.py)
                 |
                 v
Локальное хранилище data.json
```

`main.py` одновременно предоставляет REST API и отдаёт фронтенд из папки `static/`. Поэтому приложение запускается одним сервером на одном порту, а запросы интерфейса выполняются к тому же адресу.

## Структура проекта

```text
.
├── main.py            # FastAPI-приложение и REST API
├── requirements.txt   # зависимости Python
├── data.json          # локально сохранённые расходы
└── static/
    └── index.html     # React-интерфейс
```

## Установка и запуск

Требуется Python 3.10 или новее.

```powershell
git clone <URL-репозитория>
cd <папка-проекта>
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
uvicorn main:app --reload
```

После запуска откройте [http://127.0.0.1:8000/](http://127.0.0.1:8000/).

Для проверки работоспособности API доступен адрес [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health), который должен вернуть:

```json
{"status":"ok"}
```

## Как проверить решение

1. Откройте `http://127.0.0.1:8000/`.
2. В блоке «Добавить расход» введите, например, сумму `500`, выберите категорию, дату текущего месяца и нажмите «Добавить».
3. Убедитесь, что новая запись появилась в списке, а общая сумма и сумма по категории обновились.
4. Смените месяц — интерфейс покажет записи только за выбранный период.
5. Нажмите «Удалить» у записи и убедитесь, что она исчезла из списка.

Также API можно просмотреть через Swagger UI: [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs).

## Данные и интеграции

Все данные вводит пользователь. Сервер хранит их локально в файле `data.json` рядом с `main.py`. Внешних источников данных, API и сервисов нет.

## Ограничения

- Хранилище основано на одном JSON-файле и не рассчитано на многопользовательскую работу или промышленную нагрузку.
- Нет учётных записей, авторизации и разделения данных разных пользователей.
- Нет развёрнутой публичной версии: проект запускается локально.
- React и Babel загружаются из CDN, поэтому для отображения интерфейса нужен доступ к этим ресурсам.
